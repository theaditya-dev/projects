# CryptoGuard — Bitcoin Transaction & Network Correlation Intelligence

> Blockchain Forensics & AI-Powered Investigation Platform

CryptoGuard is an AI-assisted blockchain forensic investigation platform designed to help investigators identify suspicious Bitcoin transactions, detect anomalous behaviour, correlate blockchain and network-level information, and generate explainable investigation reports.

The platform combines **transaction analysis, graph-based correlation, network telemetry, heuristic analysis, and machine-learning-based anomaly detection** into a unified investigation workflow.

---

## 🚨 Problem Statement

Blockchain transactions are publicly visible, but investigating suspicious activity across large transaction datasets can be difficult.

Investigators often need to:

- Analyse large numbers of transactions
- Identify unusual transaction behaviour
- Trace relationships between wallets and transactions
- Detect groups of potentially related addresses
- Correlate blockchain activity with network-level information
- Prioritize high-risk transactions
- Generate structured investigation reports

CryptoGuard addresses these challenges through an integrated forensic investigation workflow.

---

# 💡 Our Solution

CryptoGuard provides a unified platform where investigators can:

1. Ingest transaction and related network datasets
2. Extract analytical features
3. Detect anomalous behaviour using Machine Learning
4. Identify wallet relationships using graph-based analysis
5. Correlate blockchain and network-layer information
6. Rank suspicious activities according to risk
7. Explore entity relationships interactively
8. Generate structured forensic investigation reports

- Isolation Forest anomalies
